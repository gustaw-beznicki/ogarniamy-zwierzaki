# Ogarniamy Zwierzaki

Aplikacja webowa pomagająca właścicielom zwierząt archiwizować dokumentację weterynaryjną i odnajdywać dokumenty za pomocą wyszukiwania semantycznego.

Projekt zaliczeniowy realizowany w ramach kursu 10xDevs.
