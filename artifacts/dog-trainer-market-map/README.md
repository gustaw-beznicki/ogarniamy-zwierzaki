# Mapa myśli: system dla trenerów psów

## Pliki

- `system-dla-trenerow-psow.xmind` — gotowy skoroszyt XMind z trzema arkuszami.
- `system-dla-trenerow-psow.opml` — format awaryjny do importu przez **Plik → Importuj → OPML**.

## Arkusze w pliku XMind

1. **Mapa strategiczna** — luka rynkowa, konkurencja, klient docelowy, pozycjonowanie i model danych.
2. **Scenariusze biznesowe** — osiem przypadków użycia w układzie problem → rozwiązanie → wartość.
3. **MVP i rozwój** — zakres pierwszej wersji, kolejne etapy, model biznesowy, wskaźniki i walidacja.

Mapa jest w pełni edytowalna. Kolory, układ, etykiety i gałęzie można zmienić bezpośrednio w XMind.
